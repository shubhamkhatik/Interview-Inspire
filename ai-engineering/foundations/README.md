# AI Foundations Interview Guide

Mathematical foundations, Python patterns, and core Machine Learning / Deep Learning concepts.

## Key Topics to Cover

- **Python for AI**: Generators, decorators, async/await, memory management, NumPy vectorization, PyTorch tensors and autograd.
- **Math for ML**: Linear algebra (matrix multiplication, eigenvalues), Calculus (gradient descent, backpropagation), Probability & Statistics (Bayes' theorem, distributions).
- **Core ML Concepts**: Supervised vs Unsupervised learning, Bias-Variance tradeoff, Overfitting/Underfitting, Regularization (L1/L2, Dropout), Evaluation metrics (Precision, Recall, F1, ROC-AUC).
- **Transformers Architecture**: Self-attention mechanism, Multi-head attention, Positional encoding, Encoder-only (BERT), Decoder-only (GPT), Encoder-Decoder (T5), Tokenization algorithms (BPE, WordPiece).
