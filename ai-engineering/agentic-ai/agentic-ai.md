# Agentic AI Interview Guide

Autonomous agents, Tool use, Orchestration frameworks, and Multi-agent systems.

## Key Topics to Cover

- **Agent Foundations**: ReAct pattern, Planning (Plan-and-Solve, Reflexion), Memory (Short-term context, Long-term semantic/episodic memory), Tool execution loop.
- **Function Calling & Tool Use**: Schema definitions, parameter validation, error handling, parallel tool execution.
- **MCP (Model Context Protocol)**: Clients, Servers, Transports (stdio, SSE), Resources, Tools, and Prompts.
- **Frameworks**:
  - LangChain & LangGraph (State graphs, cycles, human-in-the-loop, checkpointing)
  - LlamaIndex (Workflows, agentic query engines)
  - AutoGen & CrewAI (Multi-agent collaboration, delegation, hierarchical teams)
- **Reliability & Control**: Halting conditions, loop prevention, deterministic fallbacks.
